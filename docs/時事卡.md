# 時事卡：新增與審查流程

時事卡是跟著新聞上架、到期自動下架的卡。卡牌清單在 `site/js/news_cards.js`，改完推上 GitHub 就會自動檢查與部署。

## 一張時事卡要寫什麼

| 欄位 | 說明 |
|---|---|
| `id` | `n_` 開頭的小寫英數，例如 `n_typhoon_b` |
| `side` | `blue`、`green` 或 `shared` |
| `pair` | 藍卡指向對應的綠卡、綠卡指向藍卡（共用卡不用） |
| `type`、`cost`、`rarity`、`fx` | 跟一般卡相同；藍綠成對的兩張必須完全一樣 |
| `name`、`text` | 卡名與效果說明 |
| `flavor`、`tone` | 匿名網友留言（`push`／`boo`／`arrow`／`threads`），**不能寫成真人說的話** |
| `from`、`until` | 上架日與下架日（台北時間，含當天），格式 `YYYY-MM-DD` |
| `sources` | 至少一個 https 新聞或官方網址 |
| `topic` | 這張卡在講哪則新聞（給審查用） |
| `art` | 選填；沒有專屬插圖就用通用的「快訊」圖 |

## 規則（部署前自動擋下）

1. **11/27 前全部下架**：`until` 不能晚於 2026-11-27（投票日 11/28 全站關閉）。
2. **一定要附來源**：沒有 https 來源不能上架。
3. **藍綠對稱**：非共用卡要成對，兩邊同類型、同費用、同稀有度、同效果、同上下架日期。
4. **Jev 內容審查**：除了一般卡的規則（不把話安在真人嘴上、不嘲笑外貌家人健康、不貶低族群、不呼籲投票），時事卡另外檢查：
   - **指控真人違法、貪腐或說謊** → 機率 ≥ 0.5 就不合格
   - **提到民調** → 機率 ≥ 0.5 就不合格（11/18 起依選罷法不得出現民調）
   - 「陳述真實事件」因為有附來源，不算不合格，但會列在報告裡請人工確認
5. **平衡模擬**：模擬時會把所有時事卡一起放進卡池，藍綠勝率超出 40–60% 就停止部署。

## 寫法建議

- 寫「發生了什麼事」的場景，不寫評價：「颱風天巡水門」可以，「作秀巡水門」不行。
- 兩邊各找一則份量相當的新聞，成對上架，嘲諷強度要接近（報告裡會算兩邊被酸的總量）。
- 新聞有爭議、還在調查、或數字有不同說法的，不要做成卡。
- 卡牌風味文字一律用匿名網友的口吻。

## 臨時下架

不用改程式：在 Cloudflare 後台把卡牌 id 加進 Worker 的 `DISABLED_CARDS`（逗號分隔），或加進 `site/js/config.js` 的 `disabledCards` 後推上去。
